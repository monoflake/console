# Console

Every node at once, and where each is with what CI built: a SvelteKit app rendered from what the
nodes answered, and its live socket to the nearest node, in one Cloudflare Worker.

An archive. It was `apps/console` in [canmi21/web](https://github.com/canmi21/web), and this
repository is that history with everything else taken out; the platform it watched is being
replaced, so nothing here builds or deploys any more. The app is `apps/console`, its design is
`spec/console/` and `spec/architecture/console.md`.
